# Following these guides on Windows

Most of the instructions should work on all platforms (especially anything related to conda).
However, some of the commands may be different on Windows. Please let us know if anything is unclear or doesn't work on Windows.

One possiblility is to run 'Windows Subsystem for Linux' (WSL), which will allow you to run Linux commands on Windows.
This has the advantage that you can use the same commands for your local copy of the project as on the server.

For a guide on installing WSL see [here](https://learn.microsoft.com/en-us/windows/wsl/install).

By default this will give you an Ubuntu installation, and usually this is a good choice.
